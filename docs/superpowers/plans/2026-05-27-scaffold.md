# Life Do's — Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap the complete project skeleton — a runnable PWA with 4 navigable tab stubs, dark/light theme toggle, and all libraries wired up and ready for feature work.

**Architecture:** Vite + React + TypeScript with React Router v6 nested layout (AppLayout wraps all routes via `<Outlet />`), identical bottom tab nav on mobile and desktop with `max-w-2xl` content container, and a Zustand theme store with localStorage persistence. Supabase client and PWA service worker are configured as stubs; no feature logic is introduced here.

**Tech Stack:** React 18, Vite, TypeScript, React Router DOM v6, TanStack Query v5, Zustand 4, shadcn/ui, Tailwind CSS, vite-plugin-pwa, @supabase/supabase-js, Vitest + React Testing Library

- [ ] **Step 3.3: Implement the theme store**

Create `src/store/theme.ts`:
```ts
import { create } from 'zustand'

type Theme = 'dark' | 'light'

interface ThemeStore {
  theme: Theme
  toggle: () => void
}

function getInitialTheme(): Theme {
  return localStorage.getItem('theme') === 'light' ? 'light' : 'dark'
}

export const useThemeStore = create<ThemeStore>((set) => ({
  theme: getInitialTheme(),
  toggle: () =>
    set((state) => {
      const next: Theme = state.theme === 'dark' ? 'light' : 'dark'
      localStorage.setItem('theme', next)
      document.documentElement.classList.toggle('dark', next === 'dark')
      return { theme: next }
    }),
}))
```
